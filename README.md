# Yasno.trade

Лаборатория рыночных стратегий: погода рынка, арена ботов-аналитиков, ИИ-чат.

Прогон идей в этой версии отложен — его вернём отдельным этапом.

## Открыть

Локально: `python scripts/serve_dash.py` → http://127.0.0.1:8765

Публичный адрес: **https://yasnotrade.ru** (подключаем в Timeweb App Platform).

Гостям доступны 10 бесплатных вопросов к ИИ — без регистрации.
