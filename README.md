# Yasno.trade

Открытая лаборатория рыночных стратегий. Смотрит на золото и серебро, показывает «погоду» рынка и арену ботов-аналитиков, отвечает на вопросы по сводке простым языком.

Это не совет, куда вкладывать деньги. Это тренажёр насмотренности: какие правила ведут себя в какой погоде рынка.

Прогон идей (проверка гипотезы на истории) в этой версии отложен — вернём отдельным этапом.

## Что уже работает

- Страница лаборатории: `dashlitefin.html`
- Котировки золота и серебра из открытых источников (не из торгового терминала)
- Погода рынка: штиль / сильный ветер / турбулентность
- Арена ботов и их статистика, если лежит файл в `data/`
- Вопросы к модели по сводке на экране (на сервере — шлюз Timeweb)
- Гостям доступны бесплатные вопросы без регистрации

Публичная ссылка: [https://arcadyoc-yasno-trade-f463.twc1.net](https://arcadyoc-yasno-trade-f463.twc1.net/dashlitefin.html)

## Как открыть у себя

Нужен Python 3.

```bash
pip install -r requirements.txt
python scripts/serve_dash.py
```

Затем в браузере: [http://127.0.0.1:8765](http://127.0.0.1:8765)

На хостинге Timeweb команда запуска: `python3 scripts/serve_dash.py`. Порт берётся из переменной `PORT` (локально по умолчанию 8765).

Проверка, что сервер жив: `/api/health`.

## Папки

```
data/      данные и сводки (CSV, JSON)
docs/      описания и гайды
reports/   отчёты и проверенные параметры
scripts/   скрипты лаборатории и стратегий
tmp/       черновики, в git не попадают
```

Главные скрипты:

- `scripts/serve_dash.py` — сервер страницы, котировок и чата
- `scripts/public_market.py` — цены из открытых источников
- `scripts/collect_lab_weather.py` — обновление погоды рынка
- `scripts/lab_llm.py` — вопрос к модели
- `scripts/lab_users.py` — гости, энергия, основатель

Навык для агента (учебный файл `SKILL.md`): [`.cursor/skills/yasno-trade-lab/SKILL.md`](.cursor/skills/yasno-trade-lab/SKILL.md)

## Правила безопасности

- Не трогать живые торговые позиции и ботов без явного разрешения
- Не слать сообщения в Telegram из этого репозитория
- Перед выводом по стратегии фиксировать параметры и отрезок истории
- При сравнении вариантов всегда писать среднее число сделок в неделю
