# Как оживить публичную ссылку на дашборд

Ссылка на дашборд (та, что в README на гитхабе) работает только тогда, когда на этом компьютере запущены два процесса: сам дашборд и «туннель» — программа, которая пробрасывает его наружу, в интернет. Как только их закрываешь — ссылка перестаёт открываться у всех, кроме тебя.

Постоянный адрес: **https://5f753b99e0e60b.lhr.life**
(он не меняется, потому что привязан к твоему аккаунту на localhost.run и ключу доступа на этом компьютере)

---

## Быстрый способ (одна кнопка)

1. Проверь: **МТ5 открыт и залогинен** — без него не будет живых котировок.
2. Зайди в папку `scripts`, дважды кликни на **`open-dashboard-public.bat`**.
3. Откроются два окна. Через несколько секунд во втором окне («Публичная ссылка») появится строка `https://5f753b99e0e60b.lhr.life` — если появилась, всё готово, можно давать ссылку людям.
4. Чтобы выключить — закрой оба окна.

---

## Ручной способ (если что-то пошло не так)

Если `.bat`-файл не сработал или нужно разобраться руками — открой обычный терминал (Win → напечатать «PowerShell» → Enter) и выполни по очереди:

**Окно 1 — запустить сам дашборд:**
```
cd C:\Users\mpush\Desktop\yasno-trade\scripts
python serve_dash.py
```
Оставь это окно открытым. Если пишет что-то про «порт уже занят» (`address already in use`) — значит дашборд уже где-то работает, всё в порядке, просто закрой это окно и иди к шагу 2.

**Окно 2 (новое) — открыть туннель наружу:**
```
ssh -R 80:localhost:8765 localhost.run
```
Через пару секунд появится строка `5f753b99e0e60b.lhr.life tunneled with tls termination` — значит сработало. Если адрес перед `.lhr.life` вдруг другой — значит система не узнала твой ключ, см. раздел «Если не работает» ниже.

---

## Если что-то не работает

**«Непредвиденная лексема» / ошибка при вводе команды**
Ты в PowerShell, а команда написана под обычную командную строку (или наоборот). Если команда начинается с пути в кавычках (`"C:\Program Files\..."`) — в PowerShell перед ней нужно добавить `&`:
```
& "C:\Program Files\Git\cmd\git.exe" ...
```
В обычной командной строке (cmd) `&` не нужен и даже мешает.

**Ссылка каждый раз новая, не совпадает с `5f753b99e0e60b.lhr.life`**
Значит команда `ssh` подключается анонимно, а не под твоим аккаунтом. Проверь:
- команда должна быть `ssh -R 80:localhost:8765 localhost.run` — без `nokey@` в начале;
- ключ должен лежать в `C:\Users\mpush\.ssh\id_ed25519` (и файл `id_ed25519.pub` рядом);
- этот ключ должен быть добавлен в твой аккаунт на https://admin.localhost.run/.

**На дашборде открывается просто список файлов, а не сама страница**
Открывай ссылку без ничего после `.life` — просто `https://5f753b99e0e60b.lhr.life`, сервер сам перекинет на нужную страницу.

**Просит логин/пароль в консоли или пишет «Permission denied»**
Значит ключ не подхватился. Не вводи туда пароль от гитхаба или ещё откуда-то — это другое. Напиши мне, разберёмся.

**МТ5 не залогинен**
Котировки не появятся, карточка погоды рынка не обновится. Просто залогинься в терминал и перезапусти окно с `serve_dash.py` (закрыть и заново `python serve_dash.py`).

---

## Как всё устроено (коротко, для понимания)

- `scripts/serve_dash.py` — маленький сервер на этом компьютере. Он отдаёт страницу дашборда, тянет котировки из МТ5, отвечает ИИ-чату.
- `ssh -R ... localhost.run` — бесплатный сервис, который «прокидывает» этот локальный сервер наружу, в интернет, под удобным адресом. Сам проект при этом никуда не копируется и не «переезжает» — считай, это провод из твоего компьютера наружу.
- Гости по ссылке — это не ты: у каждого своя гостевая «энергия» (10 бесплатных действий), твой ключ основателя им не виден и не расходуется.
