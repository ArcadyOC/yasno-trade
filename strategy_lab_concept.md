# Лаборатория Стратегий (Strategy Lab)
**Концепция проекта и комплаенс-архитектура для публичной презентации**

---

## 1. Позиционирование и суть продукта

* **Статус продукта:** Образовательно-исследовательская платформа (SaaS) для статистического моделирования, бэктестинга и анализа рыночных алгоритмов.
* **Главный тезис:** «Мы не даем сигналов и не обещаем доходность. Мы предоставляем математический инструмент для объективной оценки вероятностей и проверки гипотез».
* **Целевая аудитория:** Трейдеры, разработчики алгоритмов и исследователи рыночных закономерностей.
* **Юридический статус:** Инструмент аналитики и самообучения. Не является инвестиционным консультированием, брокерской деятельностью или сервисом автоследования (ст. 4.1 и ст. 3 39-ФЗ «О рынке ценных бумаг»).

## 2. Санитария терминологии (Глоссарий комплаенса)

Для исключения любых регуляторных рисков и юридических претензий на платформе действует строгая замена терминологии:

| Запрещенный термин (Маркетинг / Сигналы) | Разрешенный термин (Статистика / Аналитика) |
| :--- | :--- |
| **Сигнал на покупку / продажу** | Срабатывание условий паттерна / Лонг-сценарий |
| **Точка входа / Тейк-профит / Стоп-лосс** | Референсный уровень / Целевой диапазон / Уровень инвалидации |
| **Прибыль / Заработок / Профит ($ / руб.)** | Математическое ожидание / R-множитель / Шаг цены |
| **Баланс демо-счета / Реальный счет** | Историческая выборка симуляции / Модельный датасет |
| **Автоследование / Копирование** | Анализ параметров готового алгоритма |
| **Надежная стратегия / Гарантия** | Историческая частота реализации паттерна |
| **Купить золото / Зайти в сделку** | Фиксация рыночной диспропорции в активе |

## 3. Ключевые функциональные модули

### Модуль 1. Дашборд аналитики алгоритмов (Lab Monitor)
* Визуализация поведения различных математических моделей (Smart Money Concepts, ценовые разрывы, ликвидность) в реальном времени.
* Отсутствие торговых кнопок («Купить», «Продать»). Только графическое отображение зон интереса и зон отмены сценария.
* Отображение контекста: трендовая структура, волатильность, фаза рынка (накопление, распределение, баланс).

### Модуль 2. ИИ-аудитор гипотез (AI Strategy Evaluator)
* Независимый аналитический блок, который объясняет логику: почему паттерн считается валидным или невалидным в текущих условиях.
* Фокус на риск-факторах: ИИ указывает на макроэкономический новостной фон, сжатие ликвидности или противоречия на старших таймфреймах.
* Оценка вероятности: предоставление исторической статистики отработки аналогичных сетапов за последние N периодов.

### Модуль 3. Песочница пользователя (Sandbox & Backtesting)
* Пространство, где пользователь задает правила своей гипотезы (например: «тест зоны FVG + снятие ликвидности на М15»).
* Платформа прогоняет гипотезу по историческим данным и выдает сухой статистический отчет без финансовых обещаний.

## 4. Метрики эффективности (Без привязки к деньгам)

Все отчеты и графики строятся исключительно на абстрактных относительных показателях:
* **Win/Loss Rate (%)** — процент сценариев, достигших целевого уровня до уровня инвалидации.
* **Risk-to-Reward (R:R)** — математическое соотношение потенциала движения к допустимому отклонению.
* **Profit Factor / Expectancy (EV)** — математическое ожидание модели на дистанции 100+ итераций.
* **Max Adverse Excursion (MAE)** — глубина просадки структуры до реализации сценария.
